# 一键生成带字幕预览

这是严格本机工作台的编辑入口，不是安装包、发布流程或自动出片上传。

1. 在本机工作台打开导入过的 MP4，或点「＋」添加素材。点「一键生成成片预览」一次即可；不需要填时间段、拖动片段或提前建立草稿。
2. 如果还在本地转写，后端记录后续任务，转写成功便自动开始全片分析，关闭网页也不会取消已接受的操作。已有字幕时直接复用，不重做转写。支持 18 秒到 3 小时的整片分析；更长视频可在「手动调整（可选）」指定较短范围。分析耗时随内容长度和设备变化。
3. 先寻找意思完整的主题，再在原顺序中去冗余、缩短经过音频测量的停顿。仅从保留内容选可独立成立的原话移到开头，不在正文重复播它。复审确切剪辑顺序、原意、片头与收尾。若首批没有安全的前置候选，再搜索一批；无符合条件的方案时明确提示，不把原顺序版本伪装成前置版本。
4. 打开推荐候选并可切换其他通过本机复审的候选。点击播放器下方按钮试听，进度条对应重组后的顺序，字幕用重组时间轴。字幕内嵌在将来的正式视频中；此时是浏览器按顺序播放原素材区间，并非已经编码的 MP4。浏览器播放顺滑度不代替人工检查每个剪口。
5. 试看确认后才打开导出审核；单纯选择、播放或关闭审核视图不保存、不覆盖现有草稿。明确确认后才保存所选候选的准确区间并使用新版本的审批指纹启动渲染。字幕校订使旧候选失效，应重新分析。

依然只使用已批准的本机 Whisper、私有本机模型和 FFmpeg，不新增云端服务或远程回退；停用仍用 `scripts/local_captions_control.py stop`，不删除原片或草稿。不可用、失败及取消应有明确状态，不能标为生成成功。

## 验收边界

- 用自制媒体和受控任务回执验证：等待转写并自动接续、失败和取消不生成候选、重试不并行、精确分析版本、三段非连续源范围及字幕重算、错误版本或未复审项目不可当成一键候选、打开候选不落盘，未经确认不能导出。
- 本机真实素材预览与可复用一键入口分别验证；真实素材、字幕、私有剪辑记录和原始验证日志只保存在本机忽略目录。模型复审不是人工观看验收，不保证传播表现，不保证每条视频都有适宜前置的独立原话。真实正式导出、完整断网验收、跨平台安装包验收仍是独立阶段。
