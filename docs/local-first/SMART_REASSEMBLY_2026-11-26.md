# 智能重剪：按主题分节、原话前置、长停顿缩短

2026-11-26（Asia/Shanghai）。起始提交 `7398809111cb2443f08013414745dea1f1238c33`；沿用 AutoClip 上游基线和原许可，继续使用 [本地字幕工作台](LOCAL_CAPTIONS_WORKSPACE_2026-11-25.md)，不安装新依赖或下载新模型。

## 怎么试用

1. 启动本地字幕工作台并刷新页面，选择已有转写的项目。
2. 在 **智能重剪** 输入原片范围（例如 `5:16` 到 `6:18`），或留空扫描全片。长片分窗口分析，界面显示进度；每节候选独立选用。
3. 展开候选，查看原片区间、逐刀原字幕、开场、正文、收尾以及建议删掉的内容。标为 **精华前置** 的候选确实将源片段移到首位；不安全的候选以 **保留原顺序** 明示。
4. **采用并预览** 后，仍可调整镜头起止、顺序和字幕。导出前须在现有审核框确认整个确切版本。下载仍是带字幕 MP4、对应 SRT、方案 JSON。
5. 用项目已有的启动/停止脚本管理服务。分析可取消；取消/不可用不会渲染任何东西。运行文件、模型输入及真实候选只在本机忽略目录。

这里的选材标准是：可独立理解、实用观点/反差、原话、有结论。不是播放量预测，也不保证爆款。不是穷尽章节索引；只展示模型给出且通过程序约束的候选。

## 技术与边界

- 本地模型依据已有字幕窗口提出主题边界、开头范围和可省略小段，只能选择原稿 cue ID。标题是编辑标签，不生成或改写原声。程序校验 ID、范围、重复和必要上下文；不接受模型编造的时间戳。
- 转为真正有序的 Studio `Draft.scenes`：原话开场 → 剩余内容按原序 → 保留原回收句。移动开头后不会在原位置再播一次。阈值严格时会沿用原顺序而不是强行重排。否定、条件、数量等限制项保护是启发式，不等于语义判断验收。长视频用约 140 秒有上下文的窗口，只负责各自核心；跨窗语义可能遗漏。
- 去气口的第一版是 **缩短测到的长停顿**：FFmpeg 音轨检测在低于约 -37 dB、持续约 0.62 秒时才确认静音；再与所保留句间空档相交，给两侧各留余量，不因字幕没字就删。紧邻句子的短吸气、环境音遮住的呼吸和词内停顿不会强删。删赘述只针对明确的短字幕范围，不用音量删除有声内容。
- 采用候选只改草稿。沿用提交前的 `plan_hash` 审批、源/SRT SHA256 校验、原版 Studio 多段渲染和时间轴重算。分析结果绑定源项目和字幕 SHA256，修改字幕后隐藏旧建议，不把它无声套用。新版本保存仍保留原素材，不覆盖历史产物。
- 重用已批准 Ollama 归档中 llama-server（经原归档复验、运行时 SHA256 固定）及批准的 Qwen3-8B GGUF（运行时 SHA256 固定）。不启动 Ollama 云能力、不下载权重；短生命周期 llama-server 使用 `--offline`，仅通过权限受限的本机 Unix socket，禁用 Web UI/MCP 代理。分析进程有单独的 OS sandbox，除这个 socket 外不允许网络；ASR/渲染的原全禁网 broker 不改。模型不可用会明确失败，不回退云端。

## 验证清单

- 合成素材：在独立数据区测试前置原音/画面、剔除可省略内容、删减后的正序正文、限制条件留存、实际重新压字幕和 MP4/SRT/JSON。回归覆盖未知 ID、越界、字幕间隔但非已测静音、假/过期审批、保留限制、当前字幕修订和模型不可用。
- 浏览器仅打开合成工程：展开一节，观看逐刀原话和删减列表，采用时播放器跳到精华原片区间，审核后真实导出并打开成片。该测试的候选来自确定性合成夹具，不拿它冒充真实模型理解水平。
- 已批准实际模型通过 Unix socket 返回 JSON；分析沙箱的 IPv4、IPv6 及本机 TCP 出口测试均得 EPERM。未进行物理断网全应用验收或完整 OS 流量观察。
