# 二检、人物近景与本片专名

本机一键分析在第一轮通读、选题、剪辑和复审后，再检查每个初审通过的实际片段。词表不等于专业知识模型，也不代替核对原片。

- 二检复读最终顺序和上下文。独立成条的短迟疑声需要本机模型确认；去掉后逐刀再读。声学静音跨字幕交接时，可在非证据句安全余量内缩短；问答、引证、长句中没有可靠定位的单字不硬切。新剪法不通顺则复审原剪法；仍不确定就排除，不凭初审结果判二检通过。
- 可给片头镜头做轻近景，随后保持余下镜头原景。macOS 可选本地 Vision 在三个采样点确认稳定单人，否则不自动裁。探测不到、人太小、多人和工具不可用都保留原画；这不是声纹识别。详情页能独立调当前镜头倍率和焦点，字幕不随画面放大；导出的方案和画面均使用相同参数。
- 可选助手源码为 `scripts/local_portrait.m`，已安装 Apple 命令行工具时使用本机 clang、相容的 macOS SDK、Foundation、AVFoundation、Vision、CoreGraphics、CoreMedia 编译至忽略路径 `.local/prepared/local-portrait`，无需获取人脸模型，不导出或保留帧。
- 进入“完整转写 → 本片专名词表”：每行一个正名，或“错写 => 正名”；支持手工、粘贴和 UTF-8/带 BOM 的 UTF-16 TXT。三字及以上、仅差一个同音字的中文专名可在 macOS 给出建议。同音歧义不自动替换。勾选要采用的建议并保存字幕才会创建字幕修订；保留原转写时间和版本，须重新分析修订版。
- 搜狗限显式选择的本机 `sgim_gd_usr.bin`：独立脚本 `scripts/local_sogou_terms.py` 核对本机观察到的字段长度和配对音节编号，只提取符合后缀的机构名候选，在项目私有 metadata 生成待选箱。不是通用词库解码器，不移植整库；支持“载入搜狗机构名候选”，载入后可删改再比对。没有经核实的豆包通用直连。Codex 提供的经确认正名可以相同方式进入项目词表；成品不读取 Codex 凭据、会话数据库或与项目无关的历史。
- 未批准不导出。不把程序复核当作人工听感验收。

**句内自动推拉与简体字幕。** 镜头不再按“第一镜”一律放大。二检后的核心观点必须能在某一保留镜头中精确定位，并留出回到原景的时间。确认取景后，在句首约 0.32 秒内推近，句末约 0.32 秒内回到原景；其他区间维持原景。稳定单人检测可直接用于新二检；对多人片段，允许使用本机另行验证的口型与声音活动定位结果，该结果必须绑定原文件、字幕版本、分析、片段和观点起止。不把人脸或能量相关性冒称身份识别。无可靠位置就不自动裁。

macOS 本机候选的字幕显示、批准后烧录和 SRT 均使用系统离线繁转简，字形使用现有简体中文字体；不改原始转写和原音。本机浏览器详情可由明确播放链接启动；浏览器拦截有声自动播放时保留播放按钮。
