# 选题先于剪辑：本机工作台使用说明

导入视频后在首页点一次生成。已有字幕时复用当前校订版本；可打开完整转写或下载有时间码的 SRT。首页列出本次通过的片段、原片区间和入选理由；点击一张片段卡进入独立详情页。详情可以刷新、复制本机地址、返回总览，观看该条字幕预览，核对依据与删减。不需要手动拼时间轴。浏览、播放、切换片段都不会自动保存方案或导出；明确批准后才会渲染。

## 原先与现在有何不同

旧分析虽然覆盖全片，却只在各自窗口里给主题评三档，有同档时优先用靠前的段落。它没有先建立贯穿全片的理解；“找到了可以前置的片头”也不是“该段值得传播”的证据。保留旧报告供回看，不将其重新标成新版分析。

1. **先读全篇，不挑片段。** 对每个不重叠的字幕核心范围通读原话，借相邻字幕理解上下文，记下它讲了什么、重要的前提或话题转折，关联真实字幕位置。按时间合并所有阅读笔记，形成全篇主线。超长的笔记分批合并，不要求一次把数千句塞进模型上下文。记录选定范围内的实际字幕条数和覆盖。字幕阅读、总览或逐窗复筛未完成时，不推出“全片最佳”。
2. **带着全篇主线回到原话。** 逐窗检索独立主题，分别写清适合谁、能得到什么、为何值得剪。可选机制包括新判断、对比、实用方法、案例和情绪转折。每个候选必须有三个不同的可核对区间：观点、支撑、收束。引文与源时间码由程序从字幕取出，不由模型生成。
3. **先比较选题，再投入精剪。** 五项各 0–2 档：与具体人群/情境的关联、新意、论据的具体程度、结尾兑现的收获、脱离前文能否独立理解。0 表示没有，1 普通，2 具体；总和至少 7，除新意外任一项不能为 0。按总和比较，同档优先证据与兑现。合并相互高度重叠的时间段，每轮最多精审 12 条。首页数字是“这轮筛选和复审后可以看的条数”，不是全片的客观上限；也不是传播概率。这些阈值是可测试的产品规则，没有按真实播放数据校准。
4. **只对入选区间去气口，然后再捋。** 只解码入选源区间。优先结合本机语音检测和各声道音量，无法获得可靠的声音边界时采取保守处理；不会仅凭字幕间隙或“然后”等字眼就剪掉说话。剪口避开问句后的明显停顿、保留句边余量。再精简重复/跑题，保护选题所依赖的引文；先独立复审原序正文，再尝试前置完整原话。移走后不重复播放，重排还要另行通过原意、衔接、开头、收尾复核。如果前置不合适但原序通过，标作“原序精剪”，不冒充前置。剪口听感仍由人试看。

## 方法依据与限制

- 对长稿先理解主题关系，再回到可核对的原文区间，与 [QMSum 的长会议定位与总结问题](https://aclanthology.org/2021.naacl-main.472/)相通；这里是本项目的剪辑实现，不是该论文验证的效果。
- [Berger 与 Milkman 的内容分享研究](https://doi.org/10.1509/jmr.10.0353)提供了实用性、兴趣、惊奇等选题线索。研究对象不是本工具的中文课程，不能用来预测某条的播放量。开头是否承诺了正文能交付的东西，与 [TikTok 的开头–正文–结尾创意结构](https://ads.tiktok.com/business/en-US/creative-codes)相通，但不套广告时限。
- [Silero VAD](https://github.com/snakers4/silero-vad)提供语音活动边界，[FFmpeg 静音检测](https://ffmpeg.org/ffmpeg-filters.html#silencedetect)依据音量和持续时间。两者都不能单独判定这次呼吸或沉默有没有表达作用。软件不会联网调用这些资料，没有额外模型下载、云端分析或自动发布。

此为本地开发工作台，不是桌面发行包。原始素材、转写、真实分析与剪辑记录留在忽略目录。启动和停止仍使用 `scripts/local_captions_control.py`；停止不删除原片。完整断网、双平台安装包和真实素材的人工观看验收与本次源码测试分别记录。
