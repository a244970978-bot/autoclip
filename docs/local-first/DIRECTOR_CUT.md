# 说话人近景版：先选一个讲得完的主题，再决定镜头和节奏

在已经通过二检的片段上另做一个可比较的版本，不改原片、初剪或已审核的旧剪法。首页有结果时提供「看说话人近景版」。本机分析没有可靠位置、证据或独立复审未通过时不推出这个版本。

1. 开头可以是原来已复审的问句/对话、原片较早的完整开场，或有依据的观点。用本机模型比较不同上下文长度的真实选材，检查看开头有没有必要听下去、下文是否有例证、结尾有没有回答开头。将拟采用的完整顺序交给单独一次复审核对，排除歪曲原意和接不上的方案。“值得试看”不是“将会爆”，未用流量数据校准。
2. 对候选开场采样口型和同期声音振幅。只用可区分且稳定的面部轨迹做固定裁框；没有可辨口型、多人竞争或视野不够则不抢切。第一帧即可是近景，不等于从全景开始推。短暂漏检留小余量，持续丢失则硬切回全景，不试图还原被遮住的人。算法不是身份识别，相关性不证明发言人身份。数字裁切不增加源画质。可选 macOS 助手使用已安装工具编译本仓库的 scripts/local_mouth_observations.m，链接 Foundation、Vision、ImageIO、CoreGraphics，输出到忽略目录 .local/prepared/local-mouth-observations。帧只在本机临时目录，退出后清除。
3. 候选分开场、必要背景、例证、方法和收束。常规开场和例证保留原速。信息较稀且不含关键条件、数字的过渡才允许适度加快，信息密的结尾可略慢。先删重复，不用整段倍速掩盖冗长。输出时用保持音高的音频变速；字幕、媒体和进度条按同一时间换算。
4. 繁转简不等于听写校对。只对入选主题复用已批准的 Whisper small，分两种窗口重新解码原音；需局部文字、时间和两次识别均提供支持才给替代写法，明显分歧只提示回听。两次识别不是两个独立模型，听不准或涉及否定、专名时不猜改。对照原声后可在字幕编辑器更正，保存会产生新修订，并要求重新生成和批准。变速预览不会反向改动字幕的源片时间。核心流程不需要接入输入法或云端。
