# 本地同步字幕工作台（开发预览）

2026-11-25，基于上游 `2f511907a72cbfbb8d86639f6441967b826acb6a`，本批起始提交 `958bccc522bf392d6f1d4d0367ba10a9f15dbc0f`。这是同一 fork 中新增的可运行本机入口，**不是单个视频压字脚本或只读审核 HTML，也不是已经发行的完整 Tauri 桌面包**。原版完整前端、账户/云功能入口未在此启动。

用户所说的“实时”在本批指：剪辑片段播放时，字幕随讲话时间同步显示；导出后字幕直接在视频画面里。**不指麦克风边录边听写，也不冒称逐字高亮或可靠说话人识别。**

## 1. 已实现的链路

> 本地 MP4 → 本地 Whisper 自动转写 → 系统内同步字幕预览/校对 → 审核具体区间与字幕 → 本地带字幕 MP4 + SRT + JSON 方案

- 简洁的“＋”和拖拽输入；复制导入，不移动/覆盖原件。当前只放行 MP4/H.264/AAC，有音轨；文件上限 8 GiB。不按扩展名宣称其他格式可用。
- 导入后自动运行已准备的本地 small/zh ASR，不需手动添加 SRT。已有授权素材通过校验源哈希、原始 SRT 哈希复用本机已完成的转写，没有再转写或上传。
- 字幕默认开启。播放器按当前时间显示字幕，选定多个区间时依顺序预览；“原片”可回看上下文。播放器是句级近似预览，不把分页时间当成真实词级对齐。
- 在系统内校对文字；保存原始 SRT、原始句时间/原文和逐版修订快照。纠错不捏造新词时间；有未保存修改时保留 Esc/离开保护，弹窗使用右上角小圆形 × 和原生焦点管理。
- 可编辑区间、追加/删除/上移；支持原画幅、9:16 fit 留边，以及原版 clean/box/bold/accent 基础字幕样式。初始建议取完整句末，不机械切在 30 秒处；手动切在句内仍需回看人工核实，不能假定 ASR 已精确到词。
- “导出成片”先展示区间、识别字幕、字幕开关、修订与方案哈希，再由用户确认导出；视频/字幕修改使旧批准失效，源或字幕被外部替换也不能标成成功。字幕烧录默认开；关闭烧录不丢弃独立 SRT。
- 本机后台任务、取消、转写失败重试、完成后播放/下载；旧导出保留。进程退出/重启时未完成任务标为失败，不把 partial 或旧文件当成新成功。

不承诺自动识别无误、精准逐字时间或爆款；本批没有实现四种内容策略、可靠语义完整性检查、配音、直播、网页下载或自动投稿。

## 2. 复用与新增位置

复用未修改的原版 `generate_subtitle_for_video`、`Draft/Scene`、`slice_srt`、`subtitle_line_limit`、`packaging_render.timeline` 和 `render_draft`。预览/独立 SRT 使用与原渲染器一致的分页、裁切和 30fps 对齐 offset；没有重写编码器、取景或拼接引擎，没有改标题冒称内容重组。

新增：

- `backend/services/local_captions.py`：项目/原始字幕/修订持久化、时间校验、方案哈希、任务状态与下载边界。
- `backend/local_captions_app.py`：仅本机的 HTTP/UI 入口，不调用原版广泛联网的 app factory。
- `backend/local_captions_broker.py`、`backend/local_captions_worker.py`：独立禁网工作进程及可停止的 ASR/渲染。
- `backend/assets/local_captions/`：无构建依赖的交互播放器、校对/审核界面、沿用当前全部 **13** 个语言的同键集与已批准运行文件 pin。不是另外购买/安装 UI 框架。
- `scripts/local_captions_control.py`、根目录两个 `.command`：准备检查、受限启动、停止、状态；没有安装器或自动下载。
- `backend/tests/test_local_captions.py`：本批回归，只用自制素材。`pyproject.toml` 仅将这些界面资源纳入 package-data。

## 3. 本机启动、使用和停止

本机已批准的 Python/依赖、Whisper 和 FFmpeg 准备目录仍沿用前批，不新增下载安装，也不调用 Codex 作为每次运行服务。

1. 在项目目录双击 **启动本地字幕.command**。或运行 `python3 scripts/local_captions_control.py start`。默认入口 `http://127.0.0.1:19784`。
2. 选已有素材，或“＋”/拖入新的受支持视频。等待本地转写完成；长片 CPU 转写可能较久，可取消。
3. 调整区间，点“预览”，字幕随播放器时间出现；“校对字幕”→保存。修改字幕会保留原文/时间和旧修订。
4. “导出成片”→回看区间和字幕→确认，才生成带字幕视频；完成后可播放或下载 MP4/SRT/JSON。字体/分页以实际导出为准；预览 CSS 不冒称像素级等同 libass。
5. 双击 **停止本地字幕.command**，或运行 `python3 scripts/local_captions_control.py stop`。只停止本入口自己的服务/任务，保留素材、字幕修订及旧成片。`status` 查询实际 PID 所属，不杀其他占用端口的程序。

运行数据在忽略目录 `.local/caption-workspace/`，日志位于其 `runtime/` 和各项目任务目录。禁止把这些目录提交 GitHub。模型缺失/变化时明确失败，不自动下载、不切换云服务。当前控制器只针对本机已准备的 macOS 环境，不宣称 Windows/Linux 启停已验证。

## 4. 本地安全边界与实际恢复

- 只监听数值 `127.0.0.1`；核对 Host、客户端回环、Origin/Fetch-Site，写请求另需同源自定义头；不启用 CORS、远端 Swagger 资源、账号或任意文件路径 API。媒体/页面设同源策略、no-store 和 CSP，只加载本机脚本/字体。
- 服务在回环限定的 OS sandbox 内运行，Python 禁止发起 socket connect。元数据 ffprobe 仅允许 file/pipe 协议，包括本机 HTTP 代理在内的 URL 都不能打开。
- ASR/渲染由**另行启动、禁止全部网络的 broker/worker/子进程树**执行。macOS 不允许已有 sandbox 再 `sandbox_apply`；初次实现因此失败，已保留失败记录并改为独立进程，而不是去掉禁网或关闭系统保护。
- 隔离 HOME、拒绝项目以外本用户 HOME 内容与系统钥匙串，空白继承环境；隐私/诊断关闭，不启动更新、上传、模板、遥测或发布队列。Whisper 四个固定文件和两个 native 工具均核验 pin；ASR 显式本地且 `enable_fallback=False`。
- 本轮主动探针：worker 对 IPv4/IPv6 外联及本机 HTTP 端口均得 EPERM；元数据探针对本机测试 HTTP 服务的 URL 在连接前因协议白名单拒绝，服务收到 0 次请求。同源/跨源拒绝、媒体 Range 请求亦有回归。

这不是绝对安全证明：未对电脑所有软件/浏览器扩展作安全审计；整个旧桌面应用没有因此被改成本地版。完整进程网络观测/抓包、物理断网冷启动到真实成片、全部异常与硬杀恢复、人类全片语义/听音验收仍待做，不以本次阻断探针替代。
