# 一键首推：完整、有依据的精华前置预览

本机工作台的默认路径：导入 → 一键生成 → 首推的独立播放页。首页保留其他合格片段，不再要求先挑“近景版”。若浏览器拦截有声自动播放，点播放器的播放键。只启动分析/预览，不写已保存的草稿、不触发正式导出。明确确认、通过同一版本的审批后，原有导出流程才会启动。

- **整片和选题。** 首推要求范围等于全片且覆盖核算通过。同版本、哈希和范围完全匹配时可复用完整阅读笔记，但重新筛选、对比、精剪和复审。选题靠原片可定位的观点、证据及结尾，不用音量或预计播放量代替价值。12 条是本轮精审上限，不是目标产量。
- **顺序和二检。** 先把正文按原序剪顺，再移动保留的一句原话，原位置不重复。若第一种前置的衔接实际被否决，允许换一处不重叠的原话、另审最终顺序，不能反复投票让同一句通过。新版二检分别读最终保留的原序与前置顺序，绑定实际片段次序、原字幕区间和剪口；任一不通过都不作为本轮前置首推。二检并非人耳已听过。
- **比较的是能播的成片。** 若多条前置候选通过，再把实际开头、后接正文、佐证和收束做本机匿名横比。只有回执与当前可播放决选条目及剪序吻合才称为“成片横比”；否则按全篇选题优先序从通过的前置中选择，并在详情说明。有且只有一条符合时说明是唯一合格项；没有则不强给首推。原序精剪仍按原序供选。
- **镜头和字幕。** 默认首推保持原片构图，不把人脸位置或音量当发言人证明；当前不是全片自动发言人特写。字幕按实际剪序重算，本机 macOS 默认简体；首推可使用已有本地 ASR 对本条做两套窗口复听，仅显示被保留字幕的核对提示，不静默改字。无提示不等于全部听写正确。标题和入选理由不作为原话字幕。
- **页面和边界。** 说明为什么入选、能看到什么收获，以及哪几处原话支撑它，均只在本机展示；另条候选可供对照。只为本次点击启动的分析或其转写接续跳转，不拿历史作业冒充新结果。保留原片回看、手工校订及明确导出批准。阻止发言人误切是保守策略，不证明已经实现主动发言人识别；软件回归不代替完整断网、桌面安装包或用户对成片的人工验收。
