# 严格本地版实施与验收边界

状态：A/B 及另批 chardet 已准备，Python 依赖检查通过，独立 FFmpeg 尚待批准、阶段 1 视频闭环未完成；[当前单项与字幕组件结果](CHARDET_SUPPLEMENT_RECEIPT_2026-11-25.md) 不替代下列交付门槛。以下是待实施合同，不是已实现功能。先读技术核查报告和根目录同步状态。

## 0. 上机前的隐私准备

1. 仅在隔离数据目录启动本基线；保留原配置，不加载其他应用账号、浏览器 cookies 或继承的供应商密钥。禁止外联后观察原版行为；不能为了“原版跑通”允许隐私例外。
2. 新增统一 strict-local 策略，在请求、设置保存、任务、后台服务与实际 HTTP/SDK 出口落实，不只隐藏 UI。原配置含云绑定时明确拒绝/迁移副本，不静默采用。
3. 停用诊断入队/媒体采集/上传/重试队列、PostHog/Sentry、远程 flags/字体/模板/推广、更新与自动投稿、下载/直播后台服务。严格模式下准备接口缺模型也只能解释失败，不能自动下载或转云。
4. 校验数值回环端点、端口、监听进程、模型哈希；拒绝局域网、非回环、账号信息、代理、重定向、未知/cloud 模型。本地模型服务也需限制外联，不能把“本机 HTTP 网关转云”漏掉。
5. 准备期网络名单与使用期完全分开。应用、模型服务、FFmpeg 和所有子进程纳入同一出站限制与观测范围；保留回环通信，不依赖全局关闭网络来掩盖恶意重试/后台任务。

## 1. 原版最小闭环

- 下载/准备仅使用已确认清单、固定版本与哈希，拒绝自动镜像切换；记录实际字节、授权、安装输出、进程路径。遇到缺 wheel/403/原生依赖错误先停在该组件，不安装大平台补救。
- 测试素材优先自制或用户明确授权的非敏感中文口播；源文件只读，记录 SHA256、codec、音轨、时长、尺寸、帧率、VFR/旋转情况。没有授权/语音就不标作中文真实转写验收。
- 在原版基线的隔离、外联受限环境，完成本地导入 → 真实本地 ASR → 真实本地模型分析 → 一条连续区间成片。原版内置隐私行为若被禁网阻断，记录失败和最小适配，不把修改版冒称原版成功。
- 记录墙钟时间、分阶段耗时、峰值内存/CPU、磁盘增量、模型/编码器实际设备、退出状态与输出哈希。使用真实参考句人工抽查识别、否定/条件词及时间偏差；没有设备实测不报吞吐。
- 逐项观看/听成片。此阶段不以模拟模型或手写字幕代替真实 ASR/LLM；手写字幕仅作单独渲染夹具。

## 2. 内容重组：先接数据与渲染，再加策略

复用 `Draft.scenes`、原片预览、Scene 编辑、render/字幕映射/取消恢复；不重写已有媒体引擎。

### 可检查的数据合同（待实现）

- `Source`：内部素材 ID、SHA256、可播放时长/尺寸/轨道与原始帧率；第一版只允许同一 source。内部真实路径不写入可公开的文档。
- `TranscriptRevision`：引擎/模型/版本、原始句/词时间、稳定 cue ID、原始文本、修订文本、修订原因/时间/父版本、不确定标记。修改文字不能悄悄编造新词时间；无法重新对齐时退回句级并提示。
- `Analysis`：主题、对象/时间/问题、观点/问题/结论/案例/证据角色；每项返回已有 cue ID 和上下文 ID，程序查表得时间。与原始引文逐字关联，不将新写摘要称作原话。
- `EditPlan`：模式、策略、目标观众/用途/时长/开头风格、必须保留/禁用内容、允许乱序开关、排序场景、来源 cue、原话/摘要、剪辑作用、语义风险、计划/字幕版本。
- `Approval`：源哈希 + 计划规范化哈希 + 草稿修订 + 字幕修订，明确人工批准。任何区间、顺序、字幕或策略修改使批准失效；渲染冻结该快照，拒绝过时批准，禁止直接调用导出绕过。

### 策略与防失真

- 连续模式严格一段。重组模式先证明至少三个不连续区间乱序输出，逐段原声/字幕均来自批准方案；开头取自实际原片，标题不算“结论前置”。
- 四种可配置结构：结论前置、问题开场、反差开场、痛点→方法→案例→总结。开头按完整句/必要上下文确定，不机械截成 3 秒；目标时长是约束，不优先于语义完整。
- 程序拒绝不存在的 source/cue、NaN/Inf、负时间、零/负时长、超界、片段身份不属于当前项目、禁用内容及不允许的乱序。重复/重叠需明确解释而非默默制造证据重复；不把浮点容差扩成无边界裁切。
- 将否定/条件/限定和证据绑定成不可随意拆开的语义单元。不同人、不同对象/问题/日期不能靠相邻或模型分数合并。规则检测与本地模型复核只做风险提示，不声称能数学证明语义。
- 审核表同时显示原片时间、原话与另标的摘要/作用、前后文、风险；可定位原片、改区间/顺序、换/删片段、修字幕。语义不确定时必须人工复核，或退回连续片段；不能只确认粗粒度 workflow 推荐就自动出片。

## 3. 输出与 UI

- 优先验证 MP4/H.264/AAC；其他容器/codec/无音轨/损坏文件明确报错或标为未支持，不按扩展名宣称支持。
- 横版按原画幅，竖版先用 fit/留边/本地模糊背景保全屏幕内容；自动人物取景是可选增强，取景不可靠时必须人工调整。字幕有安全区与基础样式，不用生图/云封面。
- 依据渲染器实际帧对齐时长统一重建 SRT/VTT 与输出时间轴；保存视频、重组字幕、JSON 计划和源映射到本地，不只打包视频/封面/文案。
- 使用原有顶部结构，输入区紧凑、拖拽、小型“＋”；如实现粘贴仅声明实际支持的类型。弹窗右上角小圆“×”固定可见，保留 Esc、焦点、触控范围、未保存/正在保存保护；不做侧边导航平台。
