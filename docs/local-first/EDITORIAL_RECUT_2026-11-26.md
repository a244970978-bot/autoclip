# 智能重剪：先剪正文、再前置、最后复查

基线为上一批本地工作台 `98085f0`。这不是播放器换标题，也不是先选开场再套正文。

1. **字幕 → 选题。** 沿用已保存的时间轴字幕（没有字幕先离线转写）。覆盖用户选定范围的各个窗口；找观点、实用信息或反差，而且有交代和收尾的完整章段。长片先分窗，边界带上下文，再对优先候选精剪；不承诺发现全部好内容，更不预测播放量。
2. **先定正文。** 按原序提出可去掉的完整字幕范围，区分口头赘述、实质重复和离题插话；不得裁掉必要对象、前提、否定、数字、案例或结论。独立无义语气词才可自动建议删除。字幕只有句级时间的，不能以“叠词”为由误删同一整句的有效内容，也不剪“看看”等有意义的重叠词。
3. **确认气口。** 在本机用已批准的 FFmpeg 和 faster-whisper 自带的 Silero 对照音轨及字幕间隙，按源时间确认可安全缩短的安静范围，留边保护发声；不会仅因字幕空白就删，检测不可用时仅用更保守的静音检测。
4. **从保留下来的内容选开头。** 先锁定已清理正文，再问模型哪段原话够独立、最值得前置。用字幕 ID 验证，不复制原话、不伪造时间轴，不把已经删掉的内容重新放回来。
5. **独立复查。** 单独一轮按实际顺序看开头、逐刀衔接、原意和收尾，对照原稿及删掉部分。重排不成立时复查清理后的原序；仍不确定就回退成原序连续候选并标明人工复查，不能偷偷认为已通过。模型复查是字幕层判断，不等于真人已试听、画面顺畅或发布质量保证。

工作台刷新后，选 **寻找主题并重剪**，等待处理，展开剪辑建议查看删减原因和复查结果，再 **采用并预览**。工作台标记“建议先看”的审核候选，会优先考虑有安全前置开头的版本。采用不等于导出；审批、源/字幕哈希和原版渲染的边界保持不变。

复用上一版字幕时间轴、Studio 工具及已批准的固定 Qwen 模型；结构化响应限制输出字段。模型只有本机私有 Unix socket，没有 TCP 或云端回退；素材、转写、输出方案、原日志都不得入仓。未新增下载。

合成验收覆盖：先删重复再从保留集选开头、只前置一次、独立判断拒绝变义和断句、失败后保留原顺序或连续原片、字幕对齐与声轨气口边界。实际素材仅在本机生成候选和人工预览，不自动批准或渲染。完整桌面安装包质量门禁和物理断网验收不在本批。
